# GarageTalk

Monorepo for the GarageTalk marketing homepage and the main web app, deployed on Render via Blueprint.

## Layout

```text
apps/
  homepage/   # Public marketing site (static)
  app/        # GarageTalk product (Express + Vite + Postgres)
render.yaml   # Render project: homepage + app web services
```

## Services (Render)

| Service | Blueprint name | Role | Typical URL |
|---------|----------------|------|-------------|
| Homepage | `garagetalk-homepage` | Marketing / landing | `https://garagetalk-homepage.onrender.com` |
| App | `garagetalk-app` | Product API + UI | `https://garagetalk-app.onrender.com` |
| Database | `garagetalk-db` | Postgres (`DATABASE_URL`) | Internal to Render |

Later custom domains (configure in Render after DNS is ready):

- `garagetalk.app` → homepage
- `app.garagetalk.app` → app

## Deploy with Blueprint

1. Push this repo to GitHub (`jspoon5/garagetalkapp`).
2. In Render: **New → Blueprint** and connect the repo (uses root `render.yaml`).
3. Render creates project **garagetalk** with the two web services and **garagetalk-db**.
4. `DATABASE_URL` is wired from `garagetalk-db` automatically. `SESSION_SECRET` is generated by Render.
5. In **garagetalk-app**, optionally set:
   - `ADMIN_EMAIL` / `ADMIN_PASSWORD` — initial admin
   - OpenAI, Stripe, Twilio keys as needed

On boot the app runs Drizzle migrations (`dist/migratePg.js`) then starts the server. Health check: `/api/health`.

Plans are **starter** (app) / **basic-256mb** (db) so custom domains and a persistent database work. Free web services spin down after inactivity and do not support custom domains the same way.

To use an existing Neon database instead of Render Postgres, override `DATABASE_URL` in the Dashboard (include `?sslmode=require`) and keep the same migration path.

## Local development (app)

```powershell
cd apps/app
Copy-Item .env.example .env
# Edit .env — set DATABASE_URL and SESSION_SECRET
npm install
npm run db:push
npm run dev
```

See [apps/app/README.md](apps/app/README.md) for Neon, GearHead AI, and Windows notes.

## Local preview (homepage)

Open `apps/homepage/index.html` in a browser, or serve the folder with any static file server. Update the CTA href once your Render app URL is final.

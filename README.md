# Garage Talk (production rebuild v3)

PWA-first automotive social platform per **GARAGE TALK — PRODUCTION REBUILD MASTER SPEC (v3)**.

## Layout

```text
apps/web          Vite + React PWA (served by the API in production)
apps/api          Fastify API (+ SPA static hosting)
apps/homepage     Marketing landing (Render static site)
packages/db       Drizzle schema + migrations + seeds
packages/shared   env validation, constants, shared types
packages/ai       GearHead prompts / provider-agnostic AI
packages/email    Resend + React Email
legacy/           Archived Express/Vite monolith (historical reference)
docs/             parity-deltas, data-map, invention-log, runbooks
BUILD-CERT.json   Machine-readable build certificate
BUILD-CERT.md     Human-readable certificate
render.yaml       Render Blueprint (homepage + app + Postgres + Redis)
```

## Commands

```bash
pnpm install
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm cert:render
```

Optional local Postgres/Redis: `docker compose up -d`

## Render (production)

Blueprint (`render.yaml`) provisions:

| Service | Role | URL |
|---------|------|-----|
| `garagetalk-homepage` | Marketing static site | https://garagetalk-homepage.onrender.com |
| `garagetalk-app` | Fastify API + PWA | https://garagetalk-app.onrender.com |
| `garagetalk-db` | Postgres 16 | (internal) |
| `garagetalk-redis` | Key Value (rate limit / presence) | (internal) |

App health: `GET https://garagetalk-app.onrender.com/healthz` → `{"ok":true}`

Set dashboard secrets as needed (`ADMIN_*`, Stripe, Twilio, AI, Resend). `SESSION_SECRET` is generated by Render; `DATABASE_URL` / `REDIS_URL` are wired from Blueprint resources.

Planned custom domains (after DNS cutover):

- `garagetalk.app` / `www` → homepage
- `app.garagetalk.app` → app (update `APP_BASE_URL` + `AUTH_TRUSTED_ORIGINS` when attached)
